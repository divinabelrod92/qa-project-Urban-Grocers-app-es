# Proyecto Urban Grocers

# Descripción
Con esta API se ejecutan las pruebas de la lista de comprobación 
generada para el campo "name" de la aplicación Urban Grocers.
Ejecuta las pruebas para crear un kit dentro de un usuario específico, que previamente será agregado
con un token de identificación. 

# Documentación
La documentación utilizada para las pruebas se encuentra en el link: https://cnt-0be30887-6d00-4c3a-a4d1-31b58a933d5e.containerhub.tripleten-services.com/docs/,
Recuerda reiniciar el servidor antes de empezar a trabajar.

# Tecnologías
El lenguaje principal de las pruebas fue Python, solicitando la respuesta json en pruebas específicas. 
Se trabajó con las librerías "Requests" para las solicitudes "HTTP" (GET/POST),
y "Pytest" para realizar las pruebas, las cuales fueron positivas y negativas;
solicitando en las respuestas: código 201 y 400, respectivamente.
